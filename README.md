# SOC 2 Type 1 Readiness Assessment — Simulated AU→US SaaS Expansion

**A simulated GRC engagement demonstrating end-to-end SOC 2 Type 1 readiness delivery for an Australian SaaS company expanding to the United States.**


---

## The Engagement (Simulated)

**Client:** MeridianHealth Analytics Pty Ltd — Sydney-based SaaS provider of healthcare analytics dashboards for private health insurers.

**Background:** Existing ISO/IEC 27001:2022 certification. Recently signed two US healthcare insurance clients contingent on producing a SOC 2 Type 1 report within six months. No prior SOC 2 experience.

**Engagement Scope:** SOC 2 Type 1 Readiness Assessment against the AICPA Trust Services Criteria — Security (Common Criteria), with optional Confidentiality and Availability scoping.

**Engagement Period:** Simulated 8-week readiness sprint.

---

## Why This Project

SOC 2 readiness is one of the most common GRC engagements for SaaS companies entering the US market. This project demonstrates:

1. End-to-end engagement structuring (charter → assessment → roadmap)
2. Working knowledge of the AICPA 2017 Trust Services Criteria (with 2022 points of focus)
3. Practical control-mapping skills, including ISO 27001:2022 ↔ SOC 2 Security TSC crosswalk
4. Audit-grade artefact production (Board-ready outputs)
5. Bridging Australian regulatory expertise (APRA CPS 234, Privacy Act 1988) with US-facing assurance frameworks

## Methodology

The assessment followed a five-phase approach:

1. **Scoping** — System description, in-scope services, supporting infrastructure, and applicable Trust Services Categories.
2. **Control mapping** — TSC Security common criteria mapped to existing ISO 27001 Statement of Applicability where overlap exists.
3. **Evidence walkthroughs** — Control owner interviews, documentation review, and sample evidence inspection (simulated).
4. **Gap identification** — Per-control rating: Implemented / Partially Implemented / Not Implemented, with risk rating.
5. **Remediation planning** — Findings prioritised by residual risk, mapped to remediation owners and target dates.

---

## Key Outcomes (Simulated)

- **65 SOC 2 Security TSC controls assessed** across nine common criteria categories (CC1–CC9).
- **70% control reuse** identified from existing ISO 27001:2022 ISMS — substantially reducing effort.
- **22 findings** identified across people, process, and technology.
- **8 High-severity residual risks** projected to reduce to 0 after the 90-day remediation plan.
- **18 net-new controls** required beyond the existing ISO 27001 ISMS, primarily in change management evidence retention, vendor monitoring depth, and customer-facing security commitments.
- **Board-ready Executive Summary and Risk Scorecard** produced for the CEO and Audit Committee.
